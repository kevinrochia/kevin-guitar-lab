
# Kevin Guitar Lab

## Descripción

Kevin Guitar Lab es un sitio web personal dedicado a la guitarra, la música worship y la adoración a Dios.

El proyecto comparte mi historia como guitarrista, canciones que me inspiran y los instrumentos y equipos que utilizo para explorar diferentes sonidos.

## Objetivos

- Compartir mi experiencia y aprendizaje con la guitarra.
- Presentar contenido relacionado con la música worship.
- Mostrar mi equipo musical.
- Permitir que los visitantes se comuniquen mediante un formulario de contacto.

## Tecnologías utilizadas

- HTML5 para la estructura y el contenido.
- CSS3 para los estilos visuales y el diseño responsive.
- Flexbox para organizar las tarjetas del equipo.
- CSS Grid para organizar las notas musicales.
- Google Fonts para las tipografías.
- Formspree para recibir mensajes del formulario de contacto.
- YouTube para integrar contenido multimedia.

## Estructura del proyecto

- `index.html`: página principal.
- `css/styles.css`: hoja de estilos.
- `img/`: imágenes del equipo musical.
- `README.md`: documentación del proyecto.
